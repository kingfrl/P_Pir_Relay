# **Projet : Contrôleur de Projecteur Intelligent avec ESP8266**

## **Description**
Ce projet permet de contrôler un projecteur via :
- Détection de mouvement (PIR).
- Boutons manuels (Allumage, Soirée, Nuit).
- Interface web pour la configuration.
- Communication MQTT pour l'intégration domotique.
- Mise à jour OTA pour les mises à jour logicielles.
